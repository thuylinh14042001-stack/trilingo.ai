# TriLingo.ai — Demo

Website học Việt–Anh–Trung.

## Chạy trên máy tính
Mở `index.html` bằng Google Chrome.

## Đưa lên GitHub Pages
1. Tạo GitHub repository mới.
2. Upload file `index.html` và `README.md` ở thư mục gốc.
3. Vào Settings > Pages > Build and deployment > Deploy from a branch.
4. Chọn branch `main`, thư mục `/ (root)` và Save.
5. Chờ GitHub Pages xuất bản và mở đường dẫn được cung cấp.

## Lưu ý
- Đây là bản demo HTML độc lập, mã JavaScript/CSS và dữ liệu học nằm trong file HTML.
- Tiến độ lưu bằng localStorage của trình duyệt, KHÔNG tự đồng bộ giữa máy hoặc tên miền.
- Chuyển từ file:// sang GitHub Pages sẽ không tự mang theo tiến độ học cũ.
- Microphone và phát âm phụ thuộc quyền trình duyệt và giọng có sẵn trên thiết bị.
